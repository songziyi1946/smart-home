# 家庭设置与成员管理验收（2026-11-17）

## 界面与能力边界

- 家庭与账户：家庭名称、设备记录、当前身份、账户信息、登录/访问有效期和退出登录。家庭改名、多家庭、房间维护、头像/显示名/密码修改没有现有接口，明确标为尚未提供。
- 成员与权限：管理员读取有效成员列表、刷新、邀请成员/限时访客、确认移除非管理员。成员和访客只看到自身权限说明，不调用成员列表接口，不展示邀请或移除操作。
- 邀请：明确区分邀请码 15 分钟有效期与访客从成功加入起计算的 1 小时/24 小时/7 天访问期限。邀请码仅一次使用，过期后隐藏；隐藏或关闭视图不会撤销邀请码。当前没有角色变更、管理员移交、邀请列表/撤销接口。
- 设备接入：分开说明 MockProvider、Home Assistant、MQTT 模拟器的已实现能力和 Matter/厂商直连等尚未接入功能。Provider 设备数量只来自快照，零记录不等于未配置，设备在线数不当作连接诊断。
- 管理员接入说明给出后端环境变量和现有文档位置，不提供 Token 输入或保存，不新增接入 API。
- 手机端优先账户与成员操作；邀请进入独立表单，避免成员列表与完整表单同时堆叠。常用入口保留独立手机房间浏览、自动化、缴费与空间视图；访客隐藏自动化/缴费。
- `#profile` 和 `#account` 保留，后者直接进入成员与权限视图。真实登录与本地免登录预览明确区分，预览不生成虚构成员和邀请。

## 保持的接口和安全行为

未修改后端 API、身份授权、会话、访客过滤或 SSE。成员管理继续使用 `/api/auth/members`、`/api/auth/invitations`、`/api/auth/members/:id`；退出使用原有 `/api/auth/logout`。

成员名单按需加载和手动刷新，处理首次加载、失败、重试与过期登录；成员 API 不属于 SSE 快照，页面不声称其为实时名单。管理员不能移除管理员。邀请码只保留在当前组件内存，不写浏览器持久化、业务日志或截图。

## 实际验收

Node 26.13.1，本地 3197 端口，临时 SQLite 数据库，正常鉴权（非 `--skip-login`），实际 production build 页面。

1. 管理员通过真实登录进入家庭设置，读取 3 位测试成员。
2. 在页面创建“加入后 1 小时”的访客邀请；通过现有加入接口成功加入测试访客。验证访客角色和有效期从加入时开始；再次使用同一邀请码返回 400。
3. 刷新页面成员名单，人数变为 4；手机端确认移除新访客，名单恢复为 3。其原会话请求 `/api/auth/session`、`/api/state` 和 `/api/events` 全部返回 401。
4. 成员与访客直接调用成员列表、邀请接口被服务端 403 拒绝；访客缴费写入被拒绝，快照中的账户和自动化为空。
5. 实际登录普通成员、访客，确认无成员名单/邀请按钮；访客无自动化/缴费入口，访问有效期展示正确。退出登录回到登录页面。
6. 手机“全部设备”仍进入已有独立房间视图，并重置为全部房间。
7. 桌面 1440×1000 / 1440×1100，手机 390×844、360×800；浅色与深色截图，360px `scrollWidth` 等于视口宽度。截图不包含可用邀请码、密码或会话凭据。
8. 前端 30 项、后端 40 项测试通过；typecheck/build、git diff --check 通过。构建仍有既有大包体积提示。

测试账号和设备属于隔离验收环境，不是用户真实家庭。临时服务、数据库和凭据在完成后清理。手机为浏览器尺寸模拟，未进行 iOS/Android 真机验收；本轮未重新连接真实 HA/MQTT 硬件，接入页验证的是现有能力说明与快照展示。
