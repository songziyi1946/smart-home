# 核心页面一致性与完整回归（2026-11-17）

## 本轮修复

1. 分开“请求进行中”和“因断线禁用”：场景、规则、缴费保存按钮仅在实际请求时显示加载；断线仍禁用写入。编辑页返回和账户退出不再被 SSE 断线连带禁用。
2. 场景删除、规则删除、整个场景重试使用统一 Arco 确认框，失败保留对话框与重试/取消入口。整体重试说明按当前编排执行，不回滚历史动作。
3. 删除场景提示其被多少条自动化引用；手机删除后不再把旧选择隐式映射到另一场景的删除操作。
4. 设备、房间、场景、规则、执行日志、费用记录、账户、收藏的主要空状态复用 StatusPanel，给出真实恢复路径。空设备目录不再提供无效“查看全部”操作。
5. 滑杆失败、断线或指针取消时恢复最新设备反馈；切换设备重建相应控制。命令仍由原有能力与 Provider 路径执行，不把草稿当设备真实状态。
6. 统一主按钮的主题前景色，修复场景和设备控制等页面的深色对比度；手机确认框和关闭提示按钮保持 44px 触控尺寸。
7. 手机设备管理筛选按需展开，让搜索与设备先出现；保留独立手机首页、房间和底部控制面板。
8. 首次同步失败只显示一个主要重试入口；有缓存时继续显示断线横幅和上次同步提示。VR 懒加载等待提示复用状态组件。
9. 首页“能源与缴费”入口名称与导航一致；快捷场景对所有运行中的执行记录判断，避免只检查第一条日志。

未修改后端 API、授权、会话、SSE 协议、SQLite 或 Provider。保留工作区此前所有重构内容。

| --- | --- |
