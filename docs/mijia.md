# 米家账号与真实设备

在“家庭设置 → 设备接入 → 米家账号与设备”中配置。需要工作台的真实管理员账号，不能使用本机免登录预览；成员与访客沿用设备控制权限，不能查看或修改云账号连接。

## 登录和选择家庭

1. 选择小米账号的设备所在地区，输入小米账号和密码。
2. 若小米要求图片验证码，手动填写图片内容；若要求身份验证，选择手机短信或邮箱并点击“发送验证码”，再填写收到的验证码。此流程不需要米家 App，验证步骤取决于账号的实际风控要求。
3. 登录后明确选择要接入的米家家庭。选择前不导入设备，也不保存新的云授权；替换现有账号时，完成家庭选择后才替换连接。
4. 在“关联三维房间”中，将云端房间对应到模型区域并保存。没有对应关系的设备仍可在设备页查看，不按中文名称猜测其模型位置。

账号下必须已有可访问的家庭和设备；此功能不包含新硬件配网。未找到家庭时，检查地区和账号；缺少可用设备规格的设备会计入暂不支持数量，不生成假开关。

验证上下文仅在服务端短期保留，五分钟过期；取消、退出工作台或会话过期后不能继续完成该次登录。发送短信/邮箱验证码必须由用户明确点击，重发有间隔限制。密码及临时密码摘要不写入数据库或配置，授权失效时可以重新登录。

## 实际状态与三维模型

- 使用服务端约 15 秒轮询读取云端设备；失败后退避，授权失效后停止轮询。它不是小米主动推送。
- 命令只下发一次，然后重新读取设备回报；接受请求不等于物理动作已完成，不把目标值当作实测值。
- 前端继续订阅同源 SSE，不增加 `/api/state` 定时刷新。设备来源显示“米家”，网络失败时设备离线并保留最后确认读数。
- 同一模型房间有真实设备时，房间面板和照明使用真实设备，不以示例灯掩盖真实设备的离线或未知状态。光效是房间级示意，不表示已知道每台灯具的安装坐标。
- 支持范围由 MIoT 规格的读写权限、范围和枚举决定，包括常见灯、温控、窗帘和环境传感器。不确定的清扫动作、开锁及摄像头流未接入。
- 原有示例场景不自动替换为真实设备；请在场景编辑器中明确选择实际设备。

## 授权凭据与部署

云授权以 AES-256-GCM 加密，使用当前家庭的数据密钥，保存在独立的 600 权限文件中，不进入业务 SQLite、API 快照、SSE、前端存储或日志。凭据文件必须位于业务数据目录之外，物理路径也不能通过软链接落入数据目录。

普通源码运行的默认文件为 `<SMART_HOME_DATA_DIR>.mijia.enc`；可通过服务端变量 `SMART_HOME_MIJIA_VAULT_FILE` 指定已有私有目录中的绝对文件路径。`create-household.mjs init` 新建的家庭会生成 `data.connections/` 私有目录，并在本机配置中指定其中的 `account.mijia.enc`。旧家庭配置没有该变量时，启动工具使用其各自数据目录的独立默认路径，覆盖终端中的其他家庭设置。

Docker Compose 将宿主的 `<SMART_HOME_HOST_DATA_DIR>.connections` 挂载至 `/connections`，凭据位于 `/connections/account.mijia.enc`。升级现有部署前，创建该宿主目录，权限设为 700，所有者与 app 的 UID/GID 一致；不要修改现有业务数据库或密钥。新初始化工具已创建此目录。

业务 SQLite 的维护备份不包含该独立凭据文件。停服后单独保存其加密副本和业务加密备份，密钥另行保管；也可以在恢复后重新登录。不要把自己的授权复制给朋友的独立家庭。解除绑定会清除该实例的授权并从快照中移除米家设备，不删除小米云上的家庭或设备。

## 接口与实现来源

管理员接口位于 `/api/integrations/mijia`：连接状态、`POST /login`、`POST /challenge`、`DELETE /login`、`POST /home`、`PUT /rooms`、`POST /refresh` 和 `DELETE /`。现有 `/api/devices/:id` 和场景执行通道复用规范化设备命令；管理接口保留 JSON/Origin 校验及限流，云登录失败不会冒充工作台会话 401。

此个人适配器依据当前社区云协议实现，不是小米开放平台的通用商业授权接口。无需安装整个 Home Assistant、Homebridge 或 Python SDK。源码参考与完整第三方许可证见 [NOTICE](third-party/mijia-cloud-NOTICE.md)，没有嵌入许可限定用途的官方 `ha_xiaomi_home` 代码。

测试使用模拟云响应和临时数据，覆盖密码、图片/短信/邮箱验证、Cookie 会话、失效与取消、SSRF、设备读写、映射、SSE、权限和加密存储；真实账号及硬件的最终验收需要实际登录后进行。
