# 场景与自动化页面验收（2026-11-17）

## 本次实现

- 场景：桌面卡片选择与动作详情分栏；独立编排工作区支持增删动作、排序和按 Capability 编辑值。手机直接执行、展开动作，最近失败优先。
- 自动化：以“当 / 且 / 就”表达设备变化、跨午夜时间段和场景动作；显式保留可选旧值 `from`。桌面编排与预览并列；手机优先开关、失败原因和详情，完整编辑保留二级入口。
- 预览：时间以浏览器本地时区输入，转 ISO 时刻传给现有 API；规则时间条件使用自身时区。修改输入后立即清除旧结果，迟到的请求响应不得覆盖新草稿。预览不执行、不写运行日志。
- 日志：结果筛选、按记录 ID 定位、关联场景的冻结动作结果、失败原因和未执行步骤。手机先呈现所选详情。设备状态入口及场景整体重试均可访问；重试不会只重放失败动作。
- 欢迎语示例与调试功能保留到独立标签。成员只读规则和日志；管理员管理规则；访客继续沿用服务器过滤。

## 验证记录

使用 Node 26.13.1、隔离临时 SQLite 数据库、已有 HA/MQTT Docker 实验环境和设备模拟器。浏览器通过实际构建页面连接后端，未向页面注入设备状态。

- 浏览器创建“夜间柔光”：开灯、亮度 15%；实际模拟器反馈为开启、15%。动作上移/下移、保存和 SSE 更新验证通过。
- 浏览器创建带 `from:false → to:true` 的人体感应规则；白天预览不匹配，23:30 预览匹配，修改时刻会清空旧结果。预览前后执行记录数量保持不变。
- 固定后端测试时钟 23:30（仅 `NODE_ENV=test` + 本地免登录），真实 MQTT 人体感应经 HA WS 触发规则、调用场景并反馈低亮度。
- 模拟灯离线后触发：自动化失败原因为“设备已离线”，关联场景第一步失败、第二步因前序失败未执行，浏览器由 SSE 更新。
- 手机直接禁用规则；恢复模拟灯后在日志确认整体重试，新增“动作已下发”记录，历史失败记录保留。
- 页面验收尺寸：桌面 1440×1000 / 1440×1200，手机 390×844、360×800；浅色与深色。手机 `scrollWidth` 与 viewport 宽度一致，无横向溢出。浏览器检查未发现 console error。
- 完整 `npm run test:e2e --prefix tools/device-simulator` 通过：设备控制、遥测、SSE 断线补同步、场景 CRUD/执行、规则启停/失败、旧 JSON 迁移与 SQLite 重启恢复均完成。
- 前端测试 24 项，后端 40 项，模拟器 8 项通过；前端 typecheck/build 通过。构建保留现有大包体积提示。

## 兼容性与边界

未修改后端 API、SSE 传输、授权、SQLite 模型或 Provider。命令“已下发”不代表真实设备物理动作完成，状态以 Provider 回传为准。历史自动化日志只展示已保存的规则版本与判定时刻；不把当前编辑后的时间条件伪装为历史条件。关联场景记录超出服务器保留范围时明确提示。

本轮是浏览器手机尺寸模拟，并非 iOS/Android 真机验收。既有默认场景使用 MockProvider；本轮新建测试场景明确使用 MQTT 模拟器设备。所有测试数据均位于临时数据库。
