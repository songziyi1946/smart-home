# 能源与缴费页面验收（2026-11-17）

## 数据和功能边界

现有数据仅支持手工支出（类别、分为单位的金额、日期、备注）和脱敏缴费账户。没有计量、余额、欠费、渠道账单或支付结果接口。因此费用汇总标注“已记录”，无记录的月份/类别显示“暂无记录”；水电气用量明确显示“暂无数据”，不根据费用推算用量。

保留 `/accounts`、`/expenses` 的 POST 契约以及 `/api/events` 的 SSE 快照。未改后端、鉴权、访客过滤或持久化。保持现有角色能力：家庭成员与管理员可记账及添加账户，访客不可查看缴费数据。未新增账户/记录编辑删除或支付接口。

渠道沿用现有网站，按类别显式映射，水务与燃气标注杭州适用地区。不向外链传递户号或金额；点击渠道不会生成成功记录。账户户号只在提交时使用，展示仍由后端返回脱敏字段。

## 两端体验

- 桌面：统计月份、分类汇总、六个月已记录费用、能源接入状态、缴费渠道、账户及完整历史。点击分类自动筛选历史；月份/类别可组合筛选，默认 20 条，可继续展开。
- 手机：费用概况、快捷缴费、历史记录分视图；概况直接进入缴费/记账。快捷缴费优先已保存账户。能源用量保留可展开入口，默认摘要明确“暂无数据”。
- 创建账户与记账使用独立表单页面，保留返回、保存中禁用、输入验证和服务端错误反馈；不通过前端假数据刷新概况。

## 实际验证

使用 Node 26.13.1，本地后端 3197 端口、隔离临时 SQLite 数据库，实际 production build 页面。所有费用样例都标记“验收样例”，不是用户账单。

- 浏览器记账 126.80 元，API 保存后 SSE 更新概况与历史。
- 浏览器添加测试账户，API/页面仅展示 `••••1024`；重复添加返回“该账户已存在”，表单保留。
- 通过现有 API 追加临时历史样例，共 24 条；11 月 4 条合计 336.30 元，10 月合计 334.60 元，与页面一致。
- 分类卡联动到当月/类别筛选；展开全部 24 条历史；无匹配月份显示暂无记录；手机水费筛选 6 条合计 232.00 元。
- 缴费链接检查目标、类别及新窗口行为配置；未进行渠道登录或真实付款。
- 桌面 1440px、手机 390×844 和 360×800 实际浏览器页面截图；窄屏 scrollWidth 等于 viewport 宽度。浅色、深色、无数据状态均检查。
- 前端 27 项、后端 40 项测试通过；typecheck/build 与 git diff --check 通过。构建存在原有大包体积提示。

手机截图属于浏览器尺寸模拟，未进行 iOS/Android 真机测试；渠道支付流程和未接入的真实能源数据不在本轮验证范围内。临时数据库和服务在验收后清理，现有开发服务保持不变。
