# 三维实景

`plan.ts` 使用米为单位，图纸左上角为平面原点：X 向右、Z 向下、Y 向上。

已按提供的家具尺寸图建立 12.910 m 总宽、左侧 7.530 m 和右侧 6.140 m 深度的外轮廓与主要空间关系。图纸为图片，墙体和家具位置是人工读图后的近似值，不能作为施工测量依据；层高暂定 2.7 m。

- `scene.ts`：墙体、门洞、家具、材质、照明及碰撞范围。
- `viewer.ts`：Three.js 渲染、相机、行走、户型总览、GLB 加载及资源释放。
- `index.tsx`：导航、小地图、场景设置、模型导入。
- `plan.test.mjs`：户型边界、相机位置和碰撞半径检查。

操作：拖动环顾，点击画面后使用 WASD 或方向键移动，Shift 加速，滚轮调整视角。也可使用右下角方向按钮。户型总览使用鼠标拖动旋转、右键平移、滚轮缩放。

GLB 导入仅在本机浏览器当前会话内读取，不上传、不保存。支持小于 100 MB、内嵌贴图的标准 GLB；暂未配置 Draco、Meshopt 和 KTX2 解码。导入模型按最长平面边归一化到 12.91 m，未针对自定义模型生成房间定位和小地图，行走起点按包围盒估算，需要视模型检查。原模型的尺度、坐标和房间锚点确认后应改用真实尺度和定位。

要进一步精确还原，需要向设计师索取：

1. 完整三维模型和贴图，优先 GLB；若只有 SKP/FBX/OBJ，先在建模软件中导出 GLB。
2. 带墙厚、门窗尺寸与位置的建筑平面图（DWG/PDF 最佳）。
3. 层高、梁底高度和吊顶图。
4. 家具/柜体模型、材质贴图或定制柜立面图。

照明开关仅影响三维预览；真实设备控制仍使用现有设备页面。

验证：从仓库根目录运行 `node --test frontend/src/vr/plan.test.mjs`，构建运行 `npm run build --prefix frontend`。
