# 三维实景

`plan.ts` 使用米为单位，图纸左上角为平面原点：X 向右、Z 向下、Y 向上。

户型外轮廓为 12.910 m 总宽、左侧 7.530 m 和右侧 6.140 m 深。客餐厨交界以《审批图纸》P-05 平面布置图定位，以《埠印贤府8-2-102》“客厅柜+橱柜”深化图调整柜体分段：将厨房内侧转角与平面坐标 X = 5.94 m 对齐，将客厅柜前沿设在 Z = 3.99 m，保留深化图约 0.911 m 的隐形门开口。玄关柜和岛台也按审批平面定位。其余参考场景含估算尺寸，层高仍暂按 2.7 m。

- `scene.ts`：墙体、门洞、家具、材质、照明及碰撞范围。
- `viewer.ts`：Three.js 渲染、相机、行走、户型总览、GLB 加载及资源释放。
- `index.tsx`：导航、小地图、场景设置、模型导入。
- `plan.test.mjs`：户型边界、相机位置和碰撞半径检查。
- `millwork.json`：客餐厨柜体及岛台的平面尺寸，供小地图、行走碰撞和 Blender 建模共用。
- `models/millwork.blend`：可编辑的 Blender 柜体与岛台模型。页面以原坐标加载同目录的 `millwork.glb`。修改尺寸后可运行 `blender -b --python frontend/src/vr/models/build_millwork.py` 重新生成模型。
- `furnishings.json` 与 `models/furnishings.blend`：客厅沙发、茶几、电视，以及主卫和次卫的洗手台、马桶、淋浴设施。运行 `blender -b --python frontend/src/vr/models/build_furnishings.py` 可重建源模型与网页 GLB。

客厅沙发位于窗侧并朝向柜体，餐椅调整到岛台的餐厅一侧。卫生间洁具按现有空间补齐，尺寸及造型为预览配置，具体产品和给排水点位仍需实物资料确认。导航提供主卫和次卫入口，家具与玻璃隔断的占地同步参与行走碰撞。

进入页面默认显示日间户型剖切总览，平台使用暖白和浅灰绿配色；日夜切换只影响模型预览。总览为正交投影，参考模型按 1.22 m 高度剖切墙体，隐藏顶面和吊装灯具，保留家具与灯光。拖动旋转、右键平移、滚轮缩放。点击地图或房间名称只选择空间及其设备，点击「进入房间」才移动相机；「进入漫游」从入户开始。第一人称下拖动环顾，点击画面后使用 WASD 或方向键移动，Shift 加速，滚轮调整视角，也可使用右下角方向按钮。

右栏宽度为 360–400 CSS px，工作区不足 1040 px 时改用抽屉，手机使用底部抽屉；不再对整个页面等比缩放。空间导航支持弹窗放大，场景设置和 GLB 导入位于独立设置抽屉。导入模型没有房间锚点时隐藏参考小地图并禁用房间定位。

首页和 VR 共用所选房间，餐厅/厨房归入餐厨、客卫归入次卫，设备筛选共用 `constants.ts` 中的映射。首页支持客厅示意图、全屋模型和有定位房间的模型预览；当前没有次卧模型定位，明确提示并展示全屋。模型预览按需加载，离开页面释放渲染资源。

木地板和卫生间地砖使用按米铺设的颜色、法线与粗糙度贴图。示例贴图来自 Poly Haven 的 [Oak Wood Planks](https://polyhaven.com/a/oak_wood_planks) 和 [Interior Tiles](https://polyhaven.com/a/interior_tiles)，采用 [CC0](https://polyhaven.com/license) 授权。

GLB 导入仅在本机浏览器当前会话内读取，不上传、不保存。支持小于 100 MB、内嵌贴图的标准 GLB；暂未配置 Draco、Meshopt 和 KTX2 解码。导入模型按最长平面边归一化到 12.91 m，未针对自定义模型生成房间定位和小地图，行走起点按包围盒估算，需要视模型检查。原模型的尺度、坐标和房间锚点确认后应改用真实尺度和定位。

要进一步精确还原，需要向设计师索取：

1. 完整三维模型和贴图，优先按真实尺寸导出、贴图内嵌的 GLB。若模型包含屋顶，可额外导出无顶版本供总览使用。
2. 带房间尺寸、墙厚、门窗洞口尺寸与位置的 DWG 或标注 PDF，以及净层高、梁底高度和吊顶图。
3. 地面、墙面与柜体的材质清单、铺贴方向及贴图，沙发、床、定制柜等主要家具的型号、尺寸、模型或立面图。
4. 灯位图、灯具类型和色温，若有可同时提供光通量或 IES 配光文件。各房间的日间和夜间效果图可用于校准。

参考模型照明开关仅影响三维预览；房间面板的设备开关和全屋场景通过现有设备接口执行，不与预览光照绑定。

验证：从仓库根目录运行 `node --test frontend/src/vr/plan.test.mjs frontend/src/rooms.test.mjs`，构建运行 `npm run build --prefix frontend`。
