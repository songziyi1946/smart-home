# Smart Home · 家庭控制台

把家里的设备、房间和日常开销放在一个网页里。出门前一键切换「离家」场景，回家后看看客厅温湿度、哪些设备离线，也能顺手记下一笔水电费。

**[下载一键体验包](#在电脑上试用)** · [下载源码 ZIP](https://github.com/songziyi1946/smart-home/archive/refs/heads/master.zip) · [开发与设备接入](docs/technical-guide.md)

## 可以用来做什么？

- **看看家里的情况**：按房间查看灯、空调、窗帘和扫地机器人，把常用设备收藏起来。接入传感器后，还能查看温湿度等读数。
- **一键切换场景**：把多个设备动作存成「回家」「离家」或「睡眠」，也可以设置夜间有人经过时运行「夜灯」场景。
- **和家人一起用**：管理员可以邀请家人加入，也可以给临时来访的人发放限时访问权限。
- **按空间查看设备**：在立体户型中选择房间，自动旋转放大并查看该区域的设备与环境状态，也可以切换设计全景。
- **记录家庭开销**：手动记录水、电、燃气等费用，查看近几个月的支出。缴费入口只跳转到官方渠道。

在“我的 → 家庭与账户”中，管理员可以修改家庭名称。手机、iPad 和电脑浏览器均可使用；通过 HTTPS 打开后，可以从该页面的“添加到桌面”入口安装网页应用。设备操作仍需连接家庭服务，离线打开时会提供重新连接入口。

朋友管理自己的家庭时，请为每户创建独立实例，分别保存数据、密钥和设备接入配置，参见[创建独立家庭](docs/households.md)。

## 从源码运行

1. 点击[下载源码 ZIP](https://github.com/songziyi1946/smart-home/archive/refs/heads/master.zip)并解压。也可以在 GitHub 仓库点击 **Code → Download ZIP**。
2. 安装 [Node.js 24.22.3](https://nodejs.org/en/download/archive/v24.22.3)（包含运行命令所需的 npm）。
3. 在解压后的项目文件夹中打开终端（Windows 可用 PowerShell，macOS 可用「终端」），依次执行：

   ```sh
   npm ci --prefix backend
   npm ci --prefix frontend
   npm run build --prefix frontend
   npm start --prefix backend
   ```

4. 保持终端窗口打开，在同一台电脑的浏览器访问 [http://127.0.0.1:3101](http://127.0.0.1:3101)。首次打开时，按提示创建家庭和管理员账号。

以后在同一文件夹里，只需再次运行 `npm start --prefix backend`。家庭设置和记账数据保存在这台电脑上，关闭页面不会清除它们。

## 接入家里的设备

管理员可在“家庭设置 → 设备接入”中登录小米账号，按提示完成图片、短信或邮箱验证，选择米家家庭并关联三维房间。无需米家 App；设备状态由服务端读取并同步到页面，支持的控制取决于实际设备。详见[米家账号与设备接入](docs/mijia.md)。

如果已经在使用 Home Assistant，可以按[设备接入说明](docs/technical-guide.md#home-assistant-与虚拟设备)连接支持的设备。可用的控制和读数取决于实际设备；模拟数据会单独标明。

遇到启动问题，或需要改端口、备份数据、使用 Docker Compose 配置常驻运行与 HTTPS，请查看[开发与部署指南](docs/technical-guide.md)。

首次公开部署前请阅读 [初始化、安全 Cookie 与隔离演示](docs/technical-guide.md#首次初始化安全-cookie-与隔离演示)。HTTPS 模式默认关闭首次注册入口，须先私下初始化家庭；不要直接公开未初始化的 local/免登录服务。

服务器升级提醒：已有 SQLite 家庭需先停服执行[加密迁移](docs/technical-guide.md#加密迁移备份与恢复操作)，并单独保存数据密钥；不能直接用新容器打开旧明文数据库。


## 保存三维模型与个人 AI 配置

家庭空间的“模型设置”支持上传 GLB、保存新模型、更新版本、恢复历史版本、设置默认模型及房间设备绑定。模型由家庭共享，管理员负责管理，成员可切换查看。设备实时数据继续来自 SSE，不按模型复制。详情见 [三维空间说明](frontend/src/vr/README.md)。

“家庭设置 → 我的 AI”允许真实登录的管理员和成员添加自己的 OpenAI Responses 兼容服务地址、模型名称及 API Key。连接只属于当前用户；家庭管理员也不能读取、测试或删除其他用户的连接。本机免登录预览和访客不能保存个人凭据。

配置保存不会自动调用上游。“测试连接”请求配置服务的模型列表；“识别并生成预览”和“调用 AI 更新所选房间”会使用当前账号明确选择的连接发送压缩图片及要求，并按该服务计费。普通编辑、预览和发布由本机程序处理，不调用 AI。不会自动升级模型、重新收费重试或使用其他用户配置。服务地址必须为公网 HTTPS；每次调用重新校验 DNS 并固定连接地址，拒绝私网和重定向。

密钥在独立的 AES-GCM 私有文件中保存。默认 `<data-dir>.ai.enc`；配置 `SMART_HOME_MIJIA_VAULT_FILE` 时默认与其同目录的 `personal-ai.enc`，也可用 `SMART_HOME_AI_VAULT_FILE` 指定。该文件必须在业务数据目录之外且权限为 600，不进入业务 SQLite、快照、普通家庭备份、Git 或镜像。需要恢复个人授权时，另行保管加密凭据文件和原数据密钥，或重新添加连接。


### 从户型图和全景生成

进入“家庭空间 → 模型设置 → 从户型图与全景生成”。选择自己的 AI 连接，上传 JPEG/PNG/WebP 户型图；可填写已知总宽、进深和层高作校准。装修参考支持炫云普通网页分享链接，或最多 12 张房间参考图。链接需要公开可读取，不支持绕过口令、支付、撤下/未审核、一次性或置顶分享限制。导入只读取图片及必要场景清单，不复制或执行播放器。

点击识别后，后台将图纸作为布局依据、参考图作为家具/饰面依据，返回结构化方案。任务保存在个人账号下，关闭页面不丢任务；重启中断的任务不自动再次调用 AI。识别结果需核对：缺少可靠尺寸时要求补充校准，不会自动声称精确测量。

预览中可校正外轮廓、房间分隔、墙体门窗及房间设备/全景关联；家具支持类型、直线/圆角、尺寸、位置、旋转、颜色和材质调整。可以选中房间再次调用自己的 AI 调整家具，其他房间和户型保持不变。失败/取消/中断但已有方案时，可“恢复上次方案（不调用 AI）”。管理员确认后选择保存新模型或更新原模型；成员可以生成和校正私有草稿，不能发布到家庭库。

程序根据校验后的方案生成自包含 GLB，包含凹形地面、门窗开口、10 类组合家具及内嵌程序材质；属于可编辑的参数化重建，不是设计师原始资产的逐件复制。模型版本保存结构化方案和对应来源。发布时装修来源图片随模型共享，原户型图、AI 连接和未发布任务仍只属于本人。

当前限制：每人同时 1 个导入/AI 任务，全实例 2 个；过去 24 小时最多 10 次 AI 生成/调整，每任务最多 10 次；单次最多 12,000 输出 token，图片输入合计最多 8 MiB，超限明确拒绝。个人素材最多 60 MiB、家庭 100 MiB。任务列表显示实际返回的累计用量；金额以用户服务商计费为准。备份/恢复包含加密任务、来源和图片，个人 AI 密钥仍单独保管。
